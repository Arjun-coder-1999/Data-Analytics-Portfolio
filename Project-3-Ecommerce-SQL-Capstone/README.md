# E-commerce SQL Capstone Project

## 📌 Project Overview
This project focuses on designing a relational database for an e-commerce store and performing business-style SQL analysis. The project includes database creation, table design, sample data insertion, and analytical queries.

## 🛠 Tools Used
- MySQL
- MySQL Workbench

## 🧱 Database Design
The database contains multiple related tables:

- Customers
- Products
- Orders
- Order Items
- Payments

The project demonstrates:
- Database design
- Primary keys
- Foreign keys
- Table relationships
- Realistic demo data
- Business-style SQL analysis

## 📊 Analysis Performed
The SQL file includes analysis such as:

- Total revenue
- Revenue by product
- Top customers by spend
- Best-selling products
- Cancelled orders count

## 💡 Key Learning
This project helped me understand how to design a relational database and write SQL queries to answer business questions from structured data.

## 📁 Files Included
- ecommerce_sql_capstone.sql → Complete SQL file containing database creation, table creation, data insertion, and analysis queries

## 🚀 Conclusion
This project demonstrates SQL database design, relational table structure, joins, aggregation, and business analysis using MySQL.
